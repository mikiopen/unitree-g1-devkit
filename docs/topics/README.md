## 使用方式

1. 选一个场景或模块，先定义可观察的成功条件。
2. 完成专题的最小设计练习；需要代码时从现有教程与源码入口查起。
3. 选择一种实现方式，保留既定输入、输出和错误语义。
4. 先独立验证，再接到其他环节；记录尚未具备的条件。

坐标、Nav2、MoveIt、ROS 2 Actions与宇树仿真相关资料在对应段落给出官方来源。实际采用时固定软件提交与设备环境，不能直接假定官方当前文档匹配本地所有参考工程。
