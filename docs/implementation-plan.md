# 实施计划

## 目标

建立一个不绑定具体业务的机器人二次开发学习骨架，让学习者能从电脑模拟逐步走到真实设备适配。

## 阶段

| 阶段 | 工作 | 完成标准 |
| --- | --- | --- |
| 1 框架 | 六阶段能力地图、统一教程模板 | 每个环节有输入、输出、边界和验收 |
| 2 电脑实验 | 配置、数据、协议、状态、音频和界面示例 | Windows/Linux 自动检查通过 |
| 3 设备适配 | 使用官方 SDK 实现只读状态和受控命令 | 版本明确，断连与错误可解释 |
| 4 能力扩展 | 感知、导航、操作、任务编排 | 每项有独立契约、数据和验证集 |
| 5 交付 | 部署、日志、监控、升级和回退 | 新环境可复现，故障可定位 |

## 不在核心仓库内

商业应用、客户部署、设备凭证、真实日志、训练数据、大模型权重、厂商源码镜像和未经许可的动作资产均不进入公共核心。具体项目可以在独立仓库依赖本框架。
