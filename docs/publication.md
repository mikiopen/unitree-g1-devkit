# 公开发布检查

当前工作树正在按公共学习框架整理。发布前必须同时满足内容、许可、隐私和 Git 历史四类条件。

## 内容与隐私

```bash
python tools/verify_learning.py
python tools/check_upload_credentials.py
python tools/check_publication.py
```

人工复核所有图片、日志、JSON、配置和提交说明，确认不存在真实邮箱、电话、账号、设备序列号、客户名称、现场地址、公网地址、个人目录、访问令牌或密钥。

## 许可

本项目采用 [Apache License 2.0](../LICENSE)。第三方引用见[声明](../third-party-notices/README.md)，任何许可不清楚的源码和资源都不应进入公开树。

## Git 历史

删除当前文件不能删除旧提交中的内容。若私有仓库历史曾包含敏感信息、客户资料或许可不明的第三方文件，不应直接把原仓库切换为公开。

推荐发布方式：

1. 在私有仓库完成并验证当前清理。
2. 从已清理的工作树导出文件，不携带 `.git`。
3. 在新的空仓库创建一次干净的初始提交。
4. 再运行全部检查并人工审核 GitHub 页面。
5. 确认许可证文件、仓库可见性和自动检查结果后再对外发布。

如凭证曾进入任何提交，即使准备重写历史，也应先吊销并轮换。
