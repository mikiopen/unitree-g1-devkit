# 配置说明

`configs/devkit.example.json` 是可公开的结构示例，`.local/devkit.json` 用于本机实际配置并被 Git 忽略。

## 字段

- `robot`：型号、自由度、固件、网卡、状态主题和 SDK 提交。公开示例均为空。
- `ports`：教学协议使用的命令、状态和动作端口；只代表契约，不代表厂商默认值。
- `resources`：离线模型、动作样例和日志目录。真实资源应放到 `.local/`。
- `services`：适配器入口。默认指向静态参考文件，不会启动服务。

## 教学协议

`g1devkit/mock/v1` 用于回环通信实验，`g1-learning/v1` 用于界面状态示例。它们不是宇树官方协议。协议版本、请求 ID、目标、超时和结果状态必须显式传递，未知字段和未知版本应拒绝或按文档处理。

## 配置原则

- 示例只保存结构和无害默认值。
- 设备序列号、账号、令牌、客户网络、现场地址和日志不进入 Git。
- 生产配置由部署系统注入，权限最小化，并支持轮换。
- 接口、端口或数据格式变化时，先更新契约与测试，再更新实现。
- 运行 `python g1.py preflight` 只做静态分析，不执行适配器代码。
