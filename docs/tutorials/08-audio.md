# 第 08 章：音频文件与TTS边界

> 环节B · 感知。本章成果：WAV属性报告和音频链路说明。

## 能力目标

生成并检查一份WAV测试音，分清文件有效、合成成功和实际播放三种结果。

- 解释采样率、声道、位宽与时长。
- 检查音频输入是否满足后续模型要求。
- 区分测试音、TTS与设备音频输出。

### 准备与配置

在仓库根目录运行，把生成文件放.local。下面文件名首次使用；若已存在，选择新名字，不覆盖已有录音。

## 输入输出与接口

按时间计算样本 → 转为小端有符号16位整数 → 写入WAV头和PCM数据。文件格式、音量、采样率是不同概念，不能仅改扩展名完成格式转换。

| 边界 | 约定 |
| --- | --- |
| 输入 | 生成参数或WAV文件路径 |
| 输出 | WAV文件或采样率、声道、编码和时长信息 |
| 错误边界 | 文件格式、覆盖和资源问题按示例说明处理 |

## 最小示例

### 主任务

1. 生成本地测试音：

   ```text
   python examples/08-audio-demo/audio_file.py create --output .local/lesson08-tone.wav
   ```

2. 单独读取属性：

   ```text
   python examples/08-audio-demo/audio_file.py inspect .local/lesson08-tone.wav
   ```

3. 对照采样率、位宽、声道和时长。可在自己的播放器低音量播放，并记录输出设备。
4. 再执行同名create，确认拒绝覆盖；生成器和检查器读写完即退出，文件继续保留.local。

### 条件扩展：TTS

1. 选择实际合成服务，核对账号条件、接口和输出格式；凭证留在进程环境。
2. 先合成一句固定文本并保存，检查属性后验证电脑播放。
3. 需要机器人播放时，再核对其音频接口、格式和设备。综合语音原型可能包含动作分支，不用它替代独立音频实验。

## 可修改与扩展点

替换音频输入或增加TTS适配，明确采样格式与输出位置；生成文件和实际播放分别验收。

### 实践成果

比较采样率、时长与文件大小的关系。交付属性报告和“合成→文件→播放”的证据清单。对应工作：Linux音视频与AI应用集成。

## 验证方法

| 检查项 | 预期结果 | 提交证据 |
| --- | --- | --- |
| 文件属性 | 1声道、2字节位宽、16000Hz、16000帧、1秒、NONE压缩 | 属性JSON |
| 文件保护 | 同名create拒绝覆盖 | 错误提示 |
| 边界解释 | 440Hz测试音不是讲话，文件有效不证明扬声器可用 | 音频链路说明 |

### 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 文件有效但无声音 | 检查播放器、输出设备、静音、音量与声道。 |
| 速度不对 | 核对实际采样率、编码与播放器解释。 |
| 合成成功但不可读 | 确认返回的是WAV还是裸PCM，核对头部与完整性。 |
