# 第 00 章：机器人二次开发系统地图

> 环节A · 设备接入。本章成果：六环节系统图与能力边界。

## 能力目标

画出设备接入、感知、决策、执行、反馈、部署维护六环节系统图，标明运行位置、输入输出、反馈闭环与需要自行实现的能力。

- 解释六环节的职责、接口和相互依赖。
- 区分已有示例、参考源码与待实现能力。
- 根据自己的设备与目标选择扩展方向。

### 准备与配置

先打开[学习框架](../learning-framework.md)。需要了解岗位时再看[职业地图](../career-map.md)，本章不用安装全部模块。

## 输入输出与接口

设备接入 → 感知 → 决策 → 执行 → 反馈 → 部署维护。反馈返回决策形成闭环；测试、仿真与维护贯穿各环节。具体信息关系见[系统架构](../architecture.md)。

可以先画“输入一句话并查询模拟状态”的小闭环，再将感知或执行替换为目标场景所需能力。图中没有实现的部分明确标注待扩展。

| 边界 | 约定 |
| --- | --- |
| 输入 | 设备能力与一个目标场景 |
| 输出 | 标明六环节及运行位置的系统图 |
| 错误边界 | 未开放接口和未实现能力明确标注 |

## 最小示例

1. 列出设备与场景；没有机器人时使用电脑、两个模拟进程与控制端。
2. 按六环节标出运行位置、输入输出与依赖。
3. 画出反馈回到决策的路径，标明数据来源与错误处理。
4. 将视觉、导航或抓取等未提供实现的能力标为待扩展。
5. 保存系统图与能力边界，本章不启动设备服务。

## 可修改与扩展点

选择导航、抓取或交互场景，替换系统图中的输入、设备适配和输出；分别列出已有组件与待实现组件。

### 实践成果

交付系统图与能力清单，选择一个希望自行实现的扩展，说明它接收什么、输出什么、如何判断失败。
