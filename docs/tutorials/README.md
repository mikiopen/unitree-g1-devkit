## 使用约定

所有教程使用[统一六栏目](../lesson-template.md)，交代输入、输出、错误边界、可修改点和验证方法。电脑命令默认从仓库根目录执行；设备与模型扩展满足条件后再加入。03章只读状态是设备执行前置，即使主归属为反馈，也应先完成。

示例协议g1-learning/v1、维护入口g1devkit/mock/v1和设备协议各自独立。通用规划、视觉、导航、抓取等扩展方向见对应能力指南，不将参考代码当成可直接运行的完整系统。

结构依据：[course.json](../../configs/course.json)。维护时运行 `python tools/check_course.py`。
