# G1 网络记录与只读排查

现场 Wi-Fi 名称、密码、账户与固定地址不作为通用默认配置发布。用 `.local` 保存你的现场记录：机器人型号、计算机/平板 IP、机器人上位机 IP、Wi-Fi 网卡、DDS 网卡、路由与广播范围。DDS 使用 eth0 的历史值不证明现场 eth0 就正确。

先检查电脑与机器人是否在预期网段，确认 Linux `ip addr`/`ip route`，然后验证 SSH 和只读 DDS。App UDP 使用 2006 指令、3840 状态，机器人内部 localhost:6789 转发动作；Redis 平板使用自己的频道和端口。广播数据到达 App 与 DDS 可达是两项独立检查。

保留脱敏的网络图、设备基线与 `read_state` 输出。不要通过随机发送历史动作编号判断网络是否通。电脑无机器人时运行 `python g1.py demo`，检查回环协议而不占用现场网络。

如果没有状态：按电源/设备可达 → 正确网卡 → IP/路由 → 防火墙/端口 → SDK/话题 → 服务进程顺序排查。登录凭证由你配置，不将默认密码写进课程。真机执行条件和停止方法见 [控制章节](tutorials/04-control.md)。
