# 用宇树 G1 项目认识工程技术职业

这套课程先让你体验工程工作，再帮助你选方向。G1 是实践载体；判断依据是你愿意持续解决哪类问题、是否理解原理、能否独立交付成果。完成一个机器人项目不等于已经具备所有相关岗位的能力。

本地图按工程工作划分方向，不提供薪资预测、招聘数量或就业保证。下表的覆盖程度指本仓库现有材料。

## 软件内部三条路线如何选择

MCU/RTOS 经常围绕小型控制器、外设和明确的时序约束工作。Linux 驱动/BSP 围绕操作系统与板卡的连接工作。Linux 应用围绕设备上的服务、通信和用户功能工作。三者都可能写 C，也都可能用 Linux 开发工具，不能只凭语言或开发电脑判断岗位类型。

试做三件事：MCU 路线观察串口收发和中断；驱动路线追踪一个外设从设备树到应用的路径；应用路线写一个可恢复的通信服务。选择你更愿意继续调查的那种问题。

完成 [课程大纲](course-syllabus.md) 中的准备单元及 00、01、05、06、07、08、10、13 的电脑实验后，使用 [职业体验实验](tracks/career-labs.md) 选择两个方向对比。03 的模拟状态可在这段期间完成；02–04 的真机部分留到设备条件明确时。

## 每次体验后的判断

在 [个人作品与复盘模板](portfolio-template.md) 中记录：独立完成了什么，哪些步骤依赖别人，最想继续解决的问题，哪些基础还不会。用 1–5 分记录兴趣、独立性、原理理解、排错耐心和交付完整度；分数用于比较自己的几次体验，不作为岗位资格认证。

选择一个主方向后，用另一个方向做配套。例如 Linux 应用 + MCU，机器人软件 + 系统集成，硬件 + 固件，AI 应用 + App。阅读代码、真实排错和完整交付都应进入作品集；展示时明确本人贡献与第三方组件。
