# 感知

设备接入 → 感知 → 决策 → 执行 → 反馈 → 部署维护

## 能力目标

把传感器原始数据转换为决策可用的观测。覆盖音频、图像、深度、点云、目标检测与跟踪、坐标变换、标定、状态估计、建图和定位。

定位回答“机器人在哪里”；路径选择归入决策，实际跟随路径归入执行。

### 感知能力拆分

| 子方向 | 核心输出 | 下一步使用者 |
| --- | --- | --- |
| 音频与语音 | 文本和识别状态 | 意图/任务模块 |
| 图像与目标 | 类别、像素框、跟踪结果 | 场景理解或空间估计 |
| 深度与标定 | 有坐标依据的空间信息 | 规划与操作模块 |
| 里程计与定位 | 位姿、有效性与参考坐标 | 导航与状态模块 |
| 建图与融合 | 环境表示与估计状态 | 规划器和诊断模块 |

每个输出都要附带适用范围。先做可独立观察的单项结果，再考虑融合。

## 前置条件

先具备[设备接入](01-access.md)与对应数据源。音频文件实验不需要机器人；ASR需要模型；相机、雷达、IMU融合等分支由开发者准备各自设备、标定与依赖。

## 输入输出与接口

| 边界 | 约定 |
| --- | --- |
| 输入 | 带采集时间、来源及必要标定信息的原始数据 |
| 输出 | 文本、目标位置、机器人位姿、地图等观测；空间数据说明坐标系和单位 |
| 错误 | 无数据、数据过期、识别失败、定位丢失和低可信观测分别处理 |

`received_at`只是接收时间，不应冒充传感器采集时间。置信度仅在模型提供或项目定义了可靠计算方法时输出，不为统一字段编造数值。

## 最小示例

1. 按[08音频文件](../tutorials/08-audio.md)生成并检查WAV，理解采样率、声道与编码。
2. 具备模型后按[09文件转写](../tutorials/09-asr.md)将WAV变成文本，记录误差。
3. 把结果作为[决策](03-decision.md)的输入；独立示例需要按教程显式传递数据。

现有最小实现集中在文件音频与ASR；视觉、融合、SLAM和标定是扩展方向，本页不宣称已提供可运行流水线。

## 可修改与扩展点

可以替换ASR、接入麦克风流、加入目标检测或姿态识别、实现相机标定、里程计与SLAM。各分支先独立输出观测，再接任务层。

从[感知专题](../topics/perception.md)定义数据契约，再自行选择相机驱动和视觉算法。外部实现需要独立核对许可证、设备适配和验证数据。

## 验证方法

| 检查项 | 预期结果 | 提交证据 |
| --- | --- | --- |
| 数据质量 | 格式、时间与来源可解释 | 样本属性与日志 |
| 感知误差 | 正确与失败样本分别统计 | 标注样本及评估结果 |
| 空间扩展 | 坐标、单位、标定和有效范围明确 | 标定记录与对照结果 |

ASR已有[本地模型推理证据](../validation.md)，不代表麦克风、视觉或定位已验证。
