# 安全说明

本仓库默认只运行静态检查、合成数据和本机回环模拟。任何真实设备运动都必须由使用者自行评估并承担现场安全责任。

## 真实设备前

- 确认硬件型号、自由度、固件和 SDK 完全匹配。
- 清空工作区，设置安全距离，使用可靠支撑并安排现场监护。
- 验证物理急停、软件急停、速度/位置/力矩限幅和通信超时。
- 从只读状态开始，再做低能量、短时、可立即中止的测试。
- 不在人员附近测试未经验证的动作、导航或抓取策略。

## 软件边界

- 未知、过期、重复、越权或格式错误的请求默认拒绝。
- 发送成功不代表执行完成；必须读取设备状态或明确结果事件。
- 断网、进程退出和界面关闭不能被视为可靠停止手段。
- 日志与录制数据在公开前必须去除设备身份、人员和现场信息。

示例代码不构成安全认证，也不替代厂商手册、风险评估和现场操作规程。
